# Self-Evaluation Report

During my internship at **Amazon Web Services Viet Nam Company Limited (Workforce Bootcamp – First Cloud AI Journey)** from **14/09/2026 to 04/12/2026**, I had the opportunity to develop my knowledge of cloud computing, explore AWS services, and apply concepts from my Information Assurance studies at FPT University to practical technical activities.

During the internship, I participated as an **AWS Cloud Engineering Intern**, contributing to research and technical activities related to **ReLoop**, a circular-economy platform designed to connect owners of used electronic devices with reuse and recycling partners. My work focused on understanding system requirements, researching AWS architecture, reviewing cloud infrastructure resources, and examining how different AWS services could support the application's functionality.

I became familiar with several AWS services, including Amazon S3, Amazon CloudFront, Amazon API Gateway, AWS Lambda, Amazon Cognito, and Amazon DynamoDB. I also reviewed the ReLoop development environment, examined CloudFront distributions and their origins, organized information about S3 buckets, and analyzed the relationships between cloud components. In addition, I researched database cost optimization through Amazon Aurora Serverless v2 and explored AWS security mechanisms in relation to web application protection and suspicious HTTP requests.

An important part of my internship was technical research and knowledge sharing. I prepared and published three AWS-related technical articles covering **Amazon S3 Lifecycle (22/10/2026), AWS Savings Plans (28/10/2026), and Amazon Aurora Serverless v2 (05/11/2026)**. These activities helped me improve my ability to research official AWS documentation, analyze practical technical scenarios, and communicate cloud-related knowledge in English. I also participated in reviewing architecture diagrams, checking service communication flows, and organizing technical documentation for the ReLoop project.

Regarding my work attitude, I demonstrated a strong willingness to learn and independently investigate unfamiliar technical topics. I gradually became more proactive in researching AWS services, identifying architectural issues, and discussing technical matters during project development. The internship also helped me recognize the importance of maintaining consistent work records, managing cloud resources carefully, controlling operational costs, and communicating technical problems effectively with team members.

### Areas for Improvement (Needs Improvement)

- **Practical AWS Knowledge & Architectural Understanding:** Although I gained exposure to multiple AWS services and participated in reviewing the ReLoop architecture, my practical experience is still developing. Some technical topics were explored through documentation and architectural analysis rather than extensive independent implementation. I need to strengthen my hands-on knowledge of IAM, VPC, Lambda, API Gateway, DynamoDB, and AWS database services. I should also improve my understanding of service dependencies, data flows, scalability, and cost-related trade-offs before making architectural decisions.

- **Engineering & Operational Discipline:** I need to become more consistent in managing daily work records, technical documentation, and project evidence. Cloud engineering also requires careful resource management, especially when working with AWS accounts that may incur usage charges. I should develop better habits in monitoring AWS Budgets, managing credentials securely, organizing technical documents, and following a structured development workflow.

- **Structured Problem-Solving & Technical Communication:** When encountering unfamiliar technical issues, I sometimes spend too much time exploring individual solutions before fully understanding the underlying problem. I need to improve my ability to identify root causes, collect relevant evidence, and evaluate alternative approaches. I should also communicate technical difficulties more systematically by explaining the problem, its impact, and possible solutions when discussing issues with mentors or teammates.

- **Cloud Security & Practical Testing:** My Information Assurance background provides a foundation for understanding security concepts, but I need more practical experience applying them to cloud environments. In particular, I should improve my knowledge of IAM least privilege, API protection, AWS WAF, security monitoring, log analysis, and cloud resource access control.

---

### Action Plan & Remediation Strategies

1. **Structured AWS Hands-on Practice:** Build small practical exercises covering IAM, VPC, S3, CloudFront, Lambda, API Gateway, and DynamoDB. Each exercise should include configuration notes, test results, and evidence so that theoretical knowledge can be connected to actual implementation.

2. **Improved Technical Troubleshooting:** Apply a structured troubleshooting process by identifying the observed problem, collecting logs and relevant information, checking official AWS documentation, investigating root causes, and validating the proposed solution before making changes.

3. **Strengthening Cloud Security Knowledge:** Continue studying IAM least privilege, secure credential management, API security, AWS WAF, and cloud monitoring. Practice evaluating security configurations and identifying potential weaknesses in controlled development environments.

4. **Better Work Management & Documentation:** Maintain consistent Daily Worklog updates and organize technical evidence throughout each project phase. Clearly distinguish completed tasks, ongoing activities, and future plans to improve progress tracking and final reporting.

5. **Continuous Technical Learning:** Continue studying AWS architecture and the Well-Architected Framework, particularly Security, Reliability, Performance Efficiency, and Cost Optimization. Improve technical English through official documentation and continue writing practical AWS articles to strengthen research and communication skills.

### Overall Self-Assessment

Overall, the internship provided valuable experience in understanding how AWS services can be combined to support real-world cloud applications. Through my involvement in ReLoop, AWS infrastructure research, architecture reviews, security-related testing, and technical blog writing, I improved my understanding of cloud engineering and strengthened my ability to learn independently.

Although I still need to develop deeper hands-on experience, improve system-level problem analysis, and become more consistent in technical operations, I believe the internship has established a useful foundation for my future development in **Cloud Engineering and Cloud Security**.
